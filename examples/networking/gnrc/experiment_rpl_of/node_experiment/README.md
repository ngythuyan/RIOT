# rpl_of_experiment

This is a RPL OF experiment. The experiment is based on the UDP benchmark module, 
sending packets and replies back and forth from other nodes to the root.
The root records these exchanges and gives overall data on the network as well as to specific nodes.
This allows for direct comparison between routing strategies.

## Setup on mesh node

To run the experiment flash this application onto at least one node. Refer to the README in the folder above this one for further information.
